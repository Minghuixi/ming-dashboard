# ✨ 明の工作台

一个清爽淡粉绿色调的手机版个人工作台 PWA 应用。

## 功能

| 分类 | 功能 |
|------|------|
| 左侧 | 每日任务、Wish List、备忘录 |
| 右侧 | 感想笔记、养生知识、变美妙招 |

### 每日任务

- 默认已预置你的 6 项日课：
  1. 吃补剂
  2. 梳头
  3. 运动1小时
  4. 读书5页
  5. 十点前躺床上
  6. mewing
- 点击圆圈即可打卡，顶部显示完成进度
- 每天会自动重置打卡状态
- 支持新增 / 删除任务

### Wish List

- 写下心愿和小目标
- 支持新增 / 删除

### 备忘录 / 感想笔记 / 养生知识 / 变美妙招

- 长文本自动保存
- 变美妙招包含「化妆笔记」和「穿搭灵感」两个子模块

## 如何在手机上使用

### 方法 1：直接用浏览器打开（最简单）

1. 将 `index.html` 和 `manifest.json` 传到手机
2. 用手机浏览器打开 `index.html`
3. 即可使用

### 方法 2：部署到 GitHub Pages（推荐，可随时随地访问）

1. 把这两个文件上传到 GitHub 仓库
2. 开启 GitHub Pages
3. 手机访问生成的链接即可

### 方法 3：添加到主屏幕（像 App 一样使用）

打开页面后：

- **iPhone（Safari）**：点击底部分享按钮 →「添加到主屏幕」
- **Android（Chrome）**：点击菜单 →「添加到主屏幕」/「安装应用」

之后手机桌面就会出现「明の工作台」图标，点开就能用，不需要网络也可以继续查看和编辑（数据存在手机里）。

## 数据存储

所有数据都保存在手机本地（localStorage），不会上传到任何服务器，换手机或清除浏览器数据会丢失，建议重要内容定期备份。

## 文件说明

- `index.html`：工作台主页面（所有功能和样式都在里面）
- `manifest.json`：PWA 配置文件
- `preview-*.png`：预览截图
